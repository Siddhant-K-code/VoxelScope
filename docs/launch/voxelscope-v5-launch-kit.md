## LinkedIn

I have published the technical story behind VoxelScope's evidence communication
compiler:

**Structure fixed the interface. Exact optimization removed the model.**

In v3, a local model proposed typed claims. The observed study failed closed in a
highly repeatable way. The main failure was not a useful hallucination count. It was
a construction-verifier mismatch, plus a lexical gate that rejected requested safe
negations.

In v4, deterministic code owned complete claim skeletons and the model selected
identifiers. The observed study returned all 270 expected tasks with no invalid
outputs. Semantic variance and 108 lexical exclusions remained, so free-form wording
still affected publication.

For v5, I moved the question before inference: what declared value could the model
still add? The publication objective was a finite exact optimization problem.
Deterministic code could maximize utility, minimize emitted bytes, verify every gate,
render final prose, close custody, and replay the result offline.

The model was therefore ineligible under the frozen objective. The control performs
zero model actions and zero network actions.

The broader rule is simple: a model should earn its place against a strong
deterministic baseline.

This is synthetic, non-clinical software evidence. It is not a model-quality, safety,
biomedical, clinical, or superiority claim.

### Structure fixed the interface. Exact optimization removed the model.

This article traces VoxelScope's evidence communication compiler from v3 through v5.

- **v3 observed model evidence:** a highly repeatable fail-closed result exposed a
  construction-verifier mismatch and four invalid outer outputs. The refusal count
  is not presented as a hallucination count.
- **v4 observed model evidence:** code-owned skeletons produced complete task-set and
  protocol compliance in the frozen study, while lexical exclusions and semantic
  variance remained.
- **v5 contract and control evidence:** the declared publication objective became a
  complete finite exact optimization problem. The pre-inference gate therefore made
  model inference ineligible.

## Short abstract

VoxelScope evolved its evidence communication boundary across three generations.
Version 3 let a local model construct typed claims and exposed a highly repeatable
construction-verifier mismatch. Version 4 moved complete typed skeletons into code,
eliminating observed protocol and task-set failures while leaving lexical exclusions
and semantic variance. Version 5 removed free-form planning text and evaluated model
eligibility before inference. Because the frozen publication objective was a finite
exact optimization problem, deterministic code could select the exact winner,
render canonical prose, verify every gate, close custody, and replay offline. The
model had no declared value endpoint left to improve. This is synthetic,
non-clinical software evidence, not a model-quality, safety, biomedical, clinical,
or superiority claim.

## Author bio

Siddhant builds offline-first research infrastructure for hash-bound evidence,

deterministic systems can own evidence identity, verification, custody, replay, and
publication while keeping model proposals inside explicit, testable boundaries.
