# Security policy

## Supported versions

The latest commit on the default branch is supported during the research prototype phase.

## Reporting

Report security vulnerabilities through GitHub private vulnerability reporting when available. Do not include secrets, PHI, patient data, medical images, cloud credentials, or proprietary model artifacts.

Relevant issues include evidence tampering, path traversal, symlink escape, checksum bypass, unsafe artifact loading, dependency compromise, hidden network access, sensitive metadata leakage, and success receipts produced from malformed or refused evidence.

## Medical research boundary

VoxelScope is research-only and is not a medical device. A security report does not establish diagnostic accuracy, clinical safety, or patient-specific validity. Public demonstrations and reproductions must use only the deterministic synthetic fixtures.
